# Chakra Fibre

Build a premium corporate B2B website for Sri Kanish Enterprises – Tiruppur, India, a leading supplier of textile labels, garment tags, and branding materials.

This website must look like a high-end ₹10,00,000+ project, with world-class UI, iconic premium SK logo, modern animations, strong visual hierarchy, and brand-level presentation.

The design should feel like a top-tier export supplier, not a local vendor or marketplace listing.

---

🎨 DESIGN REQUIREMENTS

Create an ultra-modern, elegant UI using:

- Colors: Deep Black, Charcoal Grey, Premium White, Accent Gold / Beige

- Style: Luxury minimalism + industrial precision

- UI elements:

  - Glassmorphism panels

  - Soft shadows and depth layers

  - Smooth gradients (very subtle)

  - Rounded sections with clean spacing

- Typography:

  - Bold headings (large scale)

  - Clean sans-serif (premium feel)

---

🖼️ VISUAL DIRECTION

Use high-quality images related to:

- Woven labels (close-up macro shots)

- Hang tags (luxury branding style)

- Garment production units

- Printing machines / textile processes

- Packaging and bulk production

- Fashion brand label applications

Hero sections must feel like:

Nike / Zara supplier branding + Apple-style layout

---

✨ INTERACTIVE ELEMENTS

- Smooth scroll animations (fade, slide, reveal)

- Animated counters:

  - Years experience

  - Products delivered

  - Clients served

- Horizontal product scroll sections

- Hover zoom effects on products

- Floating WhatsApp CTA

- Sticky header with blur effect

- Scroll-triggered section transitions

---

🎯 SEO REQUIREMENTS (INDIA + GLOBAL B2B)

Use these keywords naturally across headings and content:

- textile labels manufacturer in Tiruppur

- garment labels supplier India

- woven labels manufacturer India

- hang tags manufacturer Tiruppur

- clothing label supplier India

- custom garment tags manufacturer

- wash care labels supplier India

- apparel branding solutions India

Ensure:

- SEO-optimized headings (H1–H3)

- Meta-ready structure

- Fast loading

- Schema-ready content
